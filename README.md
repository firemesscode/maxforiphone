# MAX → Telegram bridge (maxforiphone)

Мост, который заводит мессенджер **MAX** внутрь Telegram-бота.

## Зачем

MAX убрали из российского App Store, и на iPhone им фактически не пользоваться.
Этот бот подключается к твоему аккаунту MAX через его веб-шлюз (тот же, что у
web-версии), и:

- присылает все входящие сообщения MAX **прямо в чат с ботом**;
- отправляет твои ответы из Telegram обратно в MAX;
- **авторизация целиком происходит в чате** — по номеру телефона и SMS-коду,
  никаких отдельных приложений и сайтов.

Для пользователя это выглядит так: открыл бота на айфоне → `/login` → ввёл
телефон → ввёл код из SMS → пользуешься MAX внутри Telegram.

## Концепт (как устроено)

```
   MAX WebSocket gateway  <───ws───►  MaxClient ──┐
                                                  │  per-user
   Telegram  ──webhook──►  grammY bot  ◄──────────┘  bridge
```

- `src/max/client.js` — адаптер над WebSocket-протоколом MAX (handshake, запрос
  SMS-кода, подтверждение, отправка/приём сообщений). Все зависящие от версии
  протокола числа собраны в одном объекте `OPCODES`.
- `src/max/manager.js` — держит по одному живому MAX-соединению на каждый
  Telegram-чат, восстанавливает их после рестарта.
- `src/bot/bot.js` — команды и конечный автомат авторизации прямо в переписке.
- `src/index.js` — HTTP-сервер, принимающий вебхук Telegram.
- `src/store.js` — файловое хранилище сессий (легко заменить на Redis/Postgres).

## Что нужно от тебя

Ровно две вещи:

1. **Токен бота** от [@BotFather](https://t.me/BotFather) → переменная `BOT_TOKEN`.
2. **Публичный HTTPS-адрес** сервера → переменная `WEBHOOK_URL`.

```bash
cp .env.example .env
# впиши BOT_TOKEN и WEBHOOK_URL
npm install
npm start            # поднимет сервер
npm run set-webhook  # пропишет вебхук в Telegram
```

Готово. Дальше всё в чате с ботом.

## Команды бота

| Команда   | Что делает                          |
|-----------|-------------------------------------|
| `/start`  | Приветствие и инструкция            |
| `/login`  | Вход в аккаунт MAX (телефон + SMS)  |
| `/status` | Статус подключения                  |
| `/logout` | Отключить аккаунт                   |

Чтобы ответить в конкретный чат MAX — сделай **reply** на пересланное
сообщение из этого чата. Обычный текст уходит в последний активный чат.

## Замечание о протоколе MAX

MAX — закрытый мессенджер, официального публичного API нет. Слой
`src/max/client.js` написан как адаптер: структура кадров и набор `OPCODES`
вынесены отдельно, так что при изменении протокола правится один файл, а логика
бота остаётся прежней. Адрес шлюза задаётся переменной `MAX_WS_URL`.

Используй с собственным аккаунтом и в рамках правил сервиса.
